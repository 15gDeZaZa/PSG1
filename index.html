03 Crear usuarios

Comando useradd

useradd permite crear un nuevo usuario en el sistema.

sudo useradd usuario # ejemplo sudo useradd theo # crear también su directorio home sudo useradd -m theo

-m crea automáticamente el directorio home del nuevo usuario.

OpciónFunción
-mCrear directorio home
-sElegir shell
-uElegir UID
theo@linux: ~
New-LocalUser "usuario" # ejemplo, sin contraseña New-LocalUser "theo" -NoPassword # el perfil / carpeta personal # se crea automáticamente al iniciar sesión

Windows crea la carpeta del perfil (C:\Users\usuario) automáticamente la primera vez que el usuario inicia sesión, a diferencia de Linux donde se pide con -m.

ParámetroFunción
-NoPasswordCrear sin contraseña
-FullNameNombre completo
-DescriptionDescripción de la cuenta
Windows PowerShell
04 Modificar usuarios

Comando usermod

usermod permite modificar usuarios ya existentes: nombre, shell o grupos.

# cambiar nombre sudo usermod -l nuevo_nombre usuario # cambiar shell sudo usermod -s /bin/bash usuario # agregar a un grupo sudo usermod -aG sudo usuario
theo@linux: ~
# cambiar nombre Rename-LocalUser -Name "usuario" -NewName "nuevo_nombre" # Windows no tiene "shell" configurable # igual que en Linux; lo más parecido es # cambiar la consola por defecto en Windows Terminal # agregar a un grupo (equivalente a sudo) Add-LocalGroupMember -Group "Administradores" -Member "usuario"
Windows no tiene un concepto idéntico de "shell de usuario"; el grupo Administradores cumple un rol parecido al grupo sudo de Linux.
Windows PowerShell
05 Eliminar usuarios

Comando userdel

userdel elimina una cuenta de usuario del sistema.

sudo userdel estudiante # elimina también el directorio home sudo userdel -r estudiante
-r elimina también el directorio home. Cuidado: puede borrar archivos personales del usuario.
theo@linux: ~
Remove-LocalUser -Name "estudiante" # Windows NO borra la carpeta de perfil sola: Remove-Item -Recurse -Force "C:\Users\estudiante"
A diferencia de Linux con -r, en Windows hay que borrar la carpeta del perfil en un paso aparte con Remove-Item.
Windows PowerShell
